# WinWin 個股資產管理

個人股票進出紀錄與資產分析網頁，可追蹤：

- **進出資料**：買進／賣出紀錄（價格、股數、手續費、證交稅）
- **資產獲利**：未實現損益、已實現損益、總損益
- **損益月曆**：每日、每週、每月的總損益，並可自選區間計算該區間損益
- **資產報酬率**：總損益 ÷ 累計投入本金
- **現金資產**：活存、交割戶、定存與負債（融資、質借），算出真正的總淨值
- **資產配置**：股票與現金的實際比重、集中度、資產類別分布
- **曝險與槓桿**：正 2、反 1 等槓桿 ETF 的真實曝險與實質槓桿倍數
- **資產配置藍圖**：正二與現金共生策略，依生活費倍數判定 73／253／343／333（或 433），
  提醒三成現金防禦、下跌加碼、質押提領與微量動態再平衡，並可一鍵套用階段目標
- **報酬風險平衡**：年化報酬、波動度、夏普值、Beta、最大回撤、風險貢獻

## 功能特色

- 移動平均成本法計算持股成本
- 台股手續費／證交稅自動建議（可手動調整）
- **自動查詢個股**：輸入代號或名稱，自動帶入股名、最新收盤與漲跌
- **一鍵更新市價**：總覽／持股頁可批次更新
- **瀏覽時自動更新市價**：開啟頁面、切回分頁或停留超過 15 分鐘會自動抓最新收盤，
  市價與損益月曆一起更新
- **損益月曆**：格子顯示單日損益與報酬率，右側是每週合計、標題是當月合計，只列出交易日
- **區間損益**：與月曆合併操作，起訖日就在月曆上方（也可用本週、本月、上月、
  近 30 日、今年、全部等快捷），算出區間總損益、報酬率與交易日數；
  點月曆的日期、週合計或當月損益也會直接帶入區間
- **自動判定槓桿倍數**：依代號與名稱辨識正 2（×2）、反 1（×-1），可手動覆寫
- **市場情境模擬**：大盤漲跌 ±30% 時，淨值會變動多少
- **槓桿 ETF 波動耗損試算**：說明為什麼正 2 的長期報酬不等於大盤的兩倍
- **一鍵套用目標權重**：等權重、依現有市值、風險平價
- **Goodinfo／玩股網快速連結**：方便查看更完整籌碼與基本面
- 資料來源：FinMind（證交所／櫃買公開資料彙整），並快取於瀏覽器
- 資料儲存於瀏覽器 LocalStorage
- 支援 JSON 匯出／匯入備份（版本 2 含現金與配置設定）

> 說明：Goodinfo、玩股網本身有 Cloudflare 防護，無法由網頁直接爬取內容；因此改用可公開呼叫的台股資料 API 自動帶價，並提供外連按鈕開啟這兩個網站。

## 線上使用

目標網址：

**https://mein227.github.io/winwin/**

### 第一次啟用（只需做一次）

部署 workflow 已就緒，但 GitHub Pages 需由你在網頁上開啟：

1. 打開：https://github.com/mein227/winwin/settings/pages
2. **Build and deployment → Source** 選擇 **GitHub Actions**
3. 再到：https://github.com/mein227/winwin/actions  
   打開最新的 **Deploy to GitHub Pages**，點 **Re-run all jobs**
4. 約 1 分鐘後即可透過上方網址瀏覽

之後每次推送到 `main`，網站會自動重新部署。

> 提醒：資料存在你瀏覽器的 LocalStorage，換裝置或清快取後不會自動同步；可用總覽頁的「匯出／匯入」備份。

## 使用流程建議

1. 到「進出紀錄」新增買進／賣出
2. 到「持股明細」更新目前市價
3. 到「現金資產」記錄手上現金與負債（沒有現金資料，配置比重與曝險都會失真）
4. 在「總覽」查看總淨值、獲利、報酬率、曝險比率與損益月曆
5. 在「資產配置」的四個子頁檢視配置、曝險、配置藍圖與報酬風險

## 計算方式

以下公式在網頁各頁面的「計算方式」卡片中也都可以展開查看。

### 每日與區間損益

| 項目 | 公式 |
| --- | --- |
| 單日總損益 | 收盤市值變化 − 當日淨投入 |
| 展開後 | Σ 期初股數 × 前日收盤 × 當日漲跌幅 + Σ 買進股數 ×(收盤 − 成交價) + Σ 賣出股數 ×(成交價 − 收盤) − 手續費 − 證交稅 |
| 單日報酬率 | 單日損益 ÷ 前一交易日收盤市值 |
| 每週總損益 | Σ 該週（週一～週五）各交易日損益 |
| 每月總損益 | Σ 該月各交易日損益 |
| 區間總損益 | Σ 起訖日之間各交易日損益 |
| 分割當日報酬 | 漲跌價差 ÷（收盤 − 漲跌價差） |

單日損益同時包含已實現與未實現，全期加總會等於總覽的總損益。只計算股票部位，
現金利息與負債利息不列入。

> 注意：損益用的是未還原的收盤價，才能和交易紀錄的成交價同基準。因此除權息當日股價
> 自然扣除股利，若沒有把股利記成交易紀錄，該日會顯示為虧損；分割與減資則改用交易所的
> 漲跌價差還原，不會出現 −96% 的假跌幅。

### 資產與配置

| 項目 | 公式 |
| --- | --- |
| 淨現金 | 現金資產合計 − 負債合計 |
| 總淨值 | 持股市值合計 + 淨現金 |
| 配置權重 | 個別市值 ÷ 總淨值 |
| 現金比重 | 淨現金 ÷ 總淨值 |
| 前三大集中度 | 權重最高三檔的權重合計 |

### 曝險與槓桿

| 項目 | 公式 |
| --- | --- |
| 單一標的曝險 | 市值 × 槓桿倍數 |
| 淨曝險 | Σ(市值 × 倍數)，反向 ETF 為負 |
| 名目曝險 | Σ&#124;市值 × 倍數&#124; |
| 曝險比率 | 淨曝險 ÷ 總淨值 |
| 實質槓桿倍數 | 淨曝險 ÷ 總淨值 |
| 內含借款 | 曝險 − 市值 |
| 現金緩衝 | 淨現金 ÷ 淨曝險 |
| 槓桿波動耗損 | (k² − k) ÷ 2 × σ² |
| 槓桿長期報酬 | k × μ − 波動耗損 |

舉例：00631L（元大台灣 50 正 2）市值 100,000 元，曝險就是 200,000 元，其中 100,000 元是
基金內部的借款。若同時有 400,000 元現金，總淨值 500,000 元、曝險比率 60%。

槓桿 ETF 每日重設槓桿，長期報酬不是大盤的兩倍：大盤先漲 10% 再跌 10%（累積 −1%）時，
正 2 為 1.2 × 0.8 = −4%。k = 2、年化波動 25% 時，每年約耗損 6.25%。

### 資產配置藍圖（正二與現金共生）

| 項目 | 公式／規則 |
| --- | --- |
| 生活費倍數 | 總淨值 ÷ 年生活費 |
| 階段配置 | 未達 10 倍→73；10–15 倍→253；15–20 倍→343；達 20 倍→333 或 433 |
| 現金防禦 | 至少約 30% 現金（或兩成原型 + 兩成現金等效） |
| 下跌加碼 | 手動設定加權指數最高點；可自訂三筆回撤門檻（預設 10%／20%／30%），達標時各加碼 5% 淨值 |
| 安全提領 | 年提領 ≤ 金融資產歷史最高點 × 提領率（預設 4%） |
| 微量再平衡 | 自動以每日收盤計算正二損益；獲利時轉回現金 ≈ 當日正二獲利 ÷ 3 |
| 執行層觸發 | 整體股權碰到「股權目標 ± 允許偏離」才建議買賣 |

藍圖會依持股自動歸類「正二／原型（含債券 ETF）／現金」，對照目標後排出優先動作
（補現金、加減碼正二、啟動下跌加碼、退休質押提醒等）。可一鍵套用本階段目標權重；
執行層仍沿用股權／現金偏離門檻，避免未大幅偏離時頻繁交易。

退休期提醒：絕對不質押正二，只質押原型或債券 ETF，並維持極低質押比例；
預留現金不能全部來自質押。

### 報酬與風險

| 項目 | 公式 |
| --- | --- |
| 日報酬 | 漲跌價差 ÷ 前一日參考價（已還原分割與配息） |
| 年化報酬 | (Π(1+r))^(252/n) − 1 |
| 年化波動度 | 日報酬標準差 × √252 |
| 組合波動 | σ_p = √(wᵀ Σ w)，Σ 為年化共變異數矩陣 |
| 夏普值 | (年化報酬 − 無風險利率) ÷ 年化波動 |
| Beta | Cov(個股, 0050) ÷ Var(0050) |
| 邊際風險 | (Σw)_i ÷ σ_p |
| 風險貢獻 | w_i × 邊際風險（合計等於 σ_p） |
| 最大回撤 | min(淨值 ÷ 歷史高點 − 1) |
| 年 95% VaR | 1.645 × σ × 總淨值 |
| 風險平價權重 | 與波動度成反比，w_i ∝ 1 ÷ σ_i |

槓桿 ETF 以市值權重搭配其自身的歷史波動計算，因為它的歷史報酬已經包含槓桿效果，
再乘上倍數會重複計算風險。

> 資料還原說明：FinMind 免費方案提供的是未調整收盤價。程式會把現金與股票股利加回來還原
> 總報酬，並在遇到 ETF 分割（例如 00631L 於 2026-03-31 由 443 元變成 19 元）時，改用交易所
> 的漲跌價差還原，避免出現 −96% 的假跌幅。
