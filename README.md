# WinWin 個股資產管理

個人股票進出紀錄與資產分析網頁，可追蹤：

- **進出資料**：買進／賣出紀錄（價格、股數、手續費、證交稅）
- **資產獲利**：未實現損益、已實現損益、總損益
- **資產報酬率**：總損益 ÷ 累計投入本金
- **現金資產**：活存、交割戶、定存與負債（融資、質借），算出真正的總淨值
- **資產配置**：股票與現金的實際比重、集中度、資產類別分布
- **曝險與槓桿**：正 2、反 1 等槓桿 ETF 的真實曝險與實質槓桿倍數
- **資產再平衡**：目標權重、偏離門檻、需買賣的金額與股數
- **報酬風險平衡**：年化報酬、波動度、夏普值、Beta、最大回撤、風險貢獻

## 功能特色

- 移動平均成本法計算持股成本
- 台股手續費／證交稅自動建議（可手動調整）
- **自動查詢個股**：輸入代號或名稱，自動帶入股名、最新收盤與漲跌
- **一鍵更新市價**：總覽／持股頁可批次更新
- **自動判定槓桿倍數**：依代號與名稱辨識正 2（×2）、反 1（×-1），可手動覆寫
- **市場情境模擬**：大盤漲跌 ±30% 時，淨值會變動多少
- **槓桿 ETF 波動耗損試算**：說明為什麼正 2 的長期報酬不等於大盤的兩倍
- **一鍵套用目標權重**：等權重、依現有市值、風險平價
- **Goodinfo／玩股網快速連結**：方便查看更完整籌碼與基本面
- 資料來源：FinMind（證交所／櫃買公開資料彙整），並快取於瀏覽器
- 資料儲存於瀏覽器 LocalStorage
- 支援 JSON 匯出／匯入備份（版本 2 含現金與配置設定）

> 說明：Goodinfo、玩股網本身有 Cloudflare 防護，無法由網頁直接爬取內容；因此改用可公開呼叫的台股資料 API 自動帶價，並提供外連按鈕開啟這兩個網站。

### 第一次啟用（只需做一次）

部署 workflow 已就緒，但 GitHub Pages 需由你在網頁上開啟：

1. 打開：https://github.com/mein227/winwin/settings/pages
2. **Build and deployment → Source** 選擇 **GitHub Actions**
3. 再到：https://github.com/mein227/winwin/actions  
   打開最新的 **Deploy to GitHub Pages**，點 **Re-run all jobs**
4. 約 1 分鐘後即可透過上方網址瀏覽

之後每次推送到 `main`，網站會自動重新部署。

> 提醒：資料存在你瀏覽器的 LocalStorage，換裝置或清快取後不會自動同步；可用總覽頁的「匯出／匯入」備份。

## 使用流程建議

1. 到「進出紀錄」新增買進／賣出
2. 到「持股明細」更新目前市價
3. 到「現金資產」記錄手上現金與負債（沒有現金資料，配置比重與曝險都會失真）
4. 在「總覽」查看總淨值、獲利、報酬率與曝險比率
5. 在「資產配置」的四個子頁檢視配置、曝險、再平衡與報酬風險

## 計算方式

以下公式在網頁各頁面的「計算方式」卡片中也都可以展開查看。

### 資產與配置

| 項目 | 公式 |
| --- | --- |
| 淨現金 | 現金資產合計 − 負債合計 |
| 總淨值 | 持股市值合計 + 淨現金 |
| 配置權重 | 個別市值 ÷ 總淨值 |
| 現金比重 | 淨現金 ÷ 總淨值 |
| 前三大集中度 | 權重最高三檔的權重合計 |

### 曝險與槓桿

| 項目 | 公式 |
| --- | --- |
| 單一標的曝險 | 市值 × 槓桿倍數 |
| 淨曝險 | Σ(市值 × 倍數)，反向 ETF 為負 |
| 名目曝險 | Σ&#124;市值 × 倍數&#124; |
| 曝險比率 | 淨曝險 ÷ 總淨值 |
| 實質槓桿倍數 | 淨曝險 ÷ 總淨值 |
| 內含借款 | 曝險 − 市值 |
| 現金緩衝 | 淨現金 ÷ 淨曝險 |
| 槓桿波動耗損 | (k² − k) ÷ 2 × σ² |
| 槓桿長期報酬 | k × μ − 波動耗損 |

舉例：00631L（元大台灣 50 正 2）市值 100,000 元，曝險就是 200,000 元，其中 100,000 元是
基金內部的借款。若同時有 400,000 元現金，總淨值 500,000 元、曝險比率 60%。

槓桿 ETF 每日重設槓桿，長期報酬不是大盤的兩倍：大盤先漲 10% 再跌 10%（累積 −1%）時，
正 2 為 1.2 × 0.8 = −4%。k = 2、年化波動 25% 時，每年約耗損 6.25%。

### 資產再平衡

| 項目 | 公式 |
| --- | --- |
| 目標金額 | 目標權重 × 總淨值 |
| 調整金額 | 目標金額 − 目前金額 |
| 需買賣股數 | 調整金額 ÷ 現價（依曝險時再除以槓桿倍數） |
| 偏離 | 目標權重 − 目前權重，&#124;偏離&#124; ≥ 門檻才建議調整 |
| 執行後現金 | 淨現金 + 賣出金額 − 買進金額 − 預估手續費與證交稅 |

計算基準可選「依市值」或「依曝險」。持有正 2 時建議用依曝險，才能真正控制風險水位。

### 報酬與風險

| 項目 | 公式 |
| --- | --- |
| 日報酬 | 漲跌價差 ÷ 前一日參考價（已還原分割與配息） |
| 年化報酬 | (Π(1+r))^(252/n) − 1 |
| 年化波動度 | 日報酬標準差 × √252 |
| 組合波動 | σ_p = √(wᵀ Σ w)，Σ 為年化共變異數矩陣 |
| 夏普值 | (年化報酬 − 無風險利率) ÷ 年化波動 |
| Beta | Cov(個股, 0050) ÷ Var(0050) |
| 邊際風險 | (Σw)_i ÷ σ_p |
| 風險貢獻 | w_i × 邊際風險（合計等於 σ_p） |
| 最大回撤 | min(淨值 ÷ 歷史高點 − 1) |
| 年 95% VaR | 1.645 × σ × 總淨值 |
| 風險平價權重 | 與波動度成反比，w_i ∝ 1 ÷ σ_i |

槓桿 ETF 以市值權重搭配其自身的歷史波動計算，因為它的歷史報酬已經包含槓桿效果，
再乘上倍數會重複計算風險。

> 資料還原說明：FinMind 免費方案提供的是未調整收盤價。程式會把現金與股票股利加回來還原
> 總報酬，並在遇到 ETF 分割（例如 00631L 於 2026-03-31 由 443 元變成 19 元）時，改用交易所
> 的漲跌價差還原，避免出現 −96% 的假跌幅。
